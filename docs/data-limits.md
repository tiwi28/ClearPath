# Data limits (feeds the closing demo slide)

Add a line every time you find a gap. Be specific: what's missing, lagged, or self-reported.

- 311 requests are self-reported: absence of a request is not absence of a barrier.
- Only 311 requests with an intersection (two street names) can be placed on the map: ~30% of accessibility requests. Address-based requests only give a 3-character postal prefix. Damaged-sidewalk reports have street names far less often (~14%) than snow/ice reports (~40-60%), so the risk model leans toward winter barriers.
- Weather comes from one station (Pearson airport), so it's the same for the whole city on a given day.
